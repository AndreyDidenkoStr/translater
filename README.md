# translater

Бесплатная утилита для macOS, которая показывает перевод слова после секунды наведения. В строке меню можно включить или выключить перевод и выбрать язык.

Разработчик — [@AndreyDidenkoStr](https://github.com/AndreyDidenkoStr).

## Скачать и запустить

1. Скачайте ZIP в разделе [Releases](https://github.com/AndreyDidenkoStr/translater/releases). Требуется macOS 15.8 или новее.
2. Распакуйте ZIP, перенесите `translater.app` в папку «Программы» и откройте его. Значок появится в строке меню.
3. Включите «Перевод при наведении» и разрешите «Универсальный доступ» в системных настройках. Затем снова включите перевод.
4. Если для выбранной языковой пары нужны модели, в меню появится кнопка «Загрузить языки». Перевод выполняется локально через Apple Translation.

Для распознавания текста с экрана в приложениях, которые не передают позицию слова, требуется отдельное разрешение на запись экрана.

Сборки в Releases подписаны локально. macOS может ограничить запуск скачанной копии без нотарификации Apple. Проект также можно открыть в Xcode и запустить через **⌘R**. Сборка проверена в Xcode 26.3.
